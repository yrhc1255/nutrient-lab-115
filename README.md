# 養分研究所：17 頁課程

依李老師核定的階段四範圍製作，共 17 頁。學生需依序完成任務才能解鎖下一頁；只有教師模式輸入 55688 才開放全部頁面。2026-09-27 依原草圖修正六類版面構圖，桌面與手機實際截圖、比對說明見 [視覺還原紀錄](verification/視覺還原紀錄.md)。先前版本僅延續配色與部分素材，不能視為已忠實實現草圖。

## 開啟

一般試用：雙擊上層專案資料夾的 [index.html](../index.html)。此單檔離線版內嵌目前課程、樣式與插畫，不需要啟動服務。其瀏覽器紀錄與下列開發預覽網址分開。說明見 [離線試用說明](../離線試用說明.txt)。

更新程式後，在本資料夾執行 `node scripts/build-offline.cjs` 重新產生離線檔；執行 `node verification/check-offline.cjs` 檢查內嵌資源與程式語法。自動瀏覽器不允許 `file://`，因此離線檔目前完成結構／語法檢查，尚未完成直接雙擊的互動驗證。

程式開發預覽：

在此資料夾執行：

```powershell
npm.cmd run dev -- --port 3107
```

開啟 http://127.0.0.1:3107 。此連接埠與其他本機專案分開；服務停止後需重新啟動。它是本機預覽，尚無對外正式網址。

## 本輪內容

- 17 頁：首頁、導讀、7 個學習頁、2 次形成性評量、2 個遊戲、閱讀、重點整理、極限挑戰、成果。
- 40 題學習／閱讀練習，含分類、配對、下拉、複選、排序、圖片標示、情境診斷、證據選取與 1 題簡答。
- 2 次形成性評量各 10 題；全部回答才能提交，首次成績永久保留於本次本機學習紀錄，後續練習不覆寫。
- 2 個遊戲各 6 回合，每題 10 分，保留首次與最高分。
- 極限挑戰共 12 題、3 次生命，依原英雄榜計分方式，具暫停及本人本機榜。
- 成果分為形成性一／二、遊戲一／二、極限挑戰、學習得分六欄。
- 教師模式使用 55688 解鎖全課程；退出或重新整理後恢復學生限制。教師示範操作不寫入學生紀錄，退出後還原進入前的學生進度，不顯示作答紀錄查閱區。

## 計分及資料行為

一般練習首次答對 3 分、第二次 2 分、第三次起 1 分，不另扣分。答錯後鎖住該次答案，按重新作答才能重試；答對後不再重複計分。重新整理保留已提交紀錄與嘗試次數，清除未提交選項及未完成題回饋。

簡答只保存學生原文、列待教師確認，不以關鍵字判對、不自動給分。本機版未提供教師評分操作。學習得分理論上限 120 分，系統可自動累積上限 117 分，其餘 3 分待教師確認。閱讀待確認時不會誤標全課精熟。

學習頁需完成探索並答對 5 題，才解鎖下一頁；評量需提交整份，遊戲需完成 6 回合並查看成果，極限挑戰需完成一場。導讀需完成圓形示範，重點整理需展開三節點並按完成。閱讀需完成探索、答對自動批改題及提交簡答，簡答待確認仍可前進，但不自動給分或標記精熟。進度分母為首頁與成果以外的 15 個課程頁。導覽按鈕、上一／下一頁與網址皆使用相同解鎖判斷，重新整理保留學生進度；舊版後段紀錄不會跳過尚未完成的前段頁面。驗證見 [逐頁解鎖驗證](verification/逐頁解鎖驗證.md)。

資料鍵為 `nutrient-lab-115:full-course:v2`，與早期不計分的樣板分開。只保存一位同學；修改班級、座號或姓名後按開始，會清除先前的答案、成績、事件與探索標記。畫面會先說明此行為。下載為 JSON，包含本次身份、逐題事件、原文與活動紀錄。

## GitHub Pages 與 GAS 成績上傳

2026-09-27 已獲授權建立公開的新 GitHub 儲存庫、GitHub Pages 與獨立 GAS 成績總表。本次不使用 Firebase。

`npm run build:pages` 會從同一份課程程式產生根目錄離線檔與 `docs/index.html`；GitHub Pages 使用 main 分支的 docs 目錄。頁面採雜湊路由，圖片與樣式內嵌，適用專案子路徑。

成績自動上傳班級、座號、姓名、六項成績及遊戲首次分數、完成頁數、閱讀簡答原文。逐題完整答案與學習進度仍留在瀏覽器；不提供跨裝置續學。離線時保留待上傳摘要，恢復連線後重試，收到對應事件的成功回條才顯示已上傳。教師示範不產生上傳事件。

GAS 使用班級＋座號＋姓名合併學生列，形成性評量保留首次收到的有效成績，遊戲及極限挑戰保留最高分，缺值不補零；同場次舊版本不覆蓋新版本。閱讀簡答仍待教師確認，不自動加分。不同裝置填寫完全相同身分時會合併總表，並非身分驗證。

GAS 僅提供成績寫入與無個資的健康檢查，不提供學生成績查詢。分數由瀏覽器計算，GAS 檢查格式、範圍與重送；此設計不提供防修改分數的正式測驗認證。成績表維持私人，表格 ID 只存於 GAS 指令碼屬性；本機部署資訊放在 Git 忽略的 `private-release/`。

GAS 原始碼在 `gas/`。2026-09-27 已由擁有者完成 Google 授權與 `setup` 初始化，並完成正式 `/exec` 健康檢查、實際寫入、同身分更新、事件重送去重與測試資料清除。
